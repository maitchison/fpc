Free Pascal IDE / Compiler -- changelog
=======================================

Most recent version first. The IDE shows this file from
Help | What's new... (loaded from the install directory at
runtime; LocateFile searches CWD, IDE startup dir, IDE install
dir).


== IDE 1.0.18 / Compiler 3.3.4 ==

Compiler
  * New syntax: `var x: T align N;` for static globals. Lets a single
    declaration request stricter alignment than the target's
    varalignmax cap. Plumbed through tstaticvarsym.varalign and
    folded into the existing explicitalign path in
    ngenutil.insertbssdata, so the BSS slot is emitted at >= N
    even when N > target_info.alignment.varalignmax. Useful for
    MMX/SSE scratch globals on go32v2 that need 8/16-byte
    alignment without a getmem-and-align dance:

        var mmreg : qword align 8;
        var sse_buf : array[0..3] of single align 16;

    N must be a power of two in 1..128. Locals/parameters are
    silently ignored (the prologue does not realign ESP).

  * Initialised vars (`var x: T align N = init;`) now produce a
    parse-time error with a hint when N exceeds the target's
    typed-const cap (constalignmax = 4 on go32v2):

        Error: `align 8` on initialised "x" exceeds target
        typed-const cap (4); declare BSS and assign in initialization.

    The cap is a DJGPP COFF object-format limitation -- per-symbol
    section alignment is encoded in only 2 bits, so a `.balign 8`
    inside `.data.n_<sym>` is silently clamped to 4 by the linker.
    The error catches it instead of letting it look correct but
    be wrong.

  * PPU long-version bumped 30 -> 31 (staticvarsym format gained
    a varalign byte). All units must be rebuilt.


== IDE 1.0.17 / Compiler 3.3.3 ==

IDE
  * Quick-Open (Ctrl+U): typing a '.' in the filter switches
    to a mask-ignoring corpus and matches against the full
    basename, so files outside the IncludeMask (e.g. play.log)
    show up as you type. Pressing Enter on a query containing
    a '.' that has no listbox match resolves the literal text
    against the project dir + every -Fu/-Fi search dir and
    opens it if found -- so 'play.log' loads even when the
    mask only covers Pascal sources.
  * File|Open, File|Open Recent, and OpenSearch no longer
    open a second editor window when the file is already
    open on the desktop -- the existing window is focused
    instead. Previously each open created a fresh window,
    so the same file could end up loaded several times in
    parallel with diverging unsaved edits. Navigation paths
    (Ctrl+Enter go-to-def, nav stack, command-line args,
    find-in-files results, breakpoints) already deduped;
    this brings the menu paths into line. File|New and
    File|New From Template still create fresh untitled
    windows.


== IDE 1.0.16 / Compiler 3.3.3 ==

IDE
  * Quick-Open (Ctrl+U): mask textbox lets you filter the file
    list by extension or name pattern; persists across sessions.
    Result list now sorts by extension priority so .pas/.pp
    sources show ahead of .ppu/.o build artefacts.
  * DOS Shell: command prompt is marked so the user can tell
    they're in a shell-out; refuses to re-enter while one is
    already running (FPISDOSSHELL env-var guard). Avoids the
    stacked-IDE / leaked-temp-files trap.
  * Editor color fixes; new INI and ASM file syntax highlighting.
  * Run profiles: named bundles of (main file, run params),
    switchable from the Run menu. Per-project, persisted with
    the desktop.
  * Alt+Up / Alt+Down: jump between interface declaration and
    implementation of the procedure under the cursor.
  * Ctrl+Enter go-to-definition; Alt+Left / Alt+Right back/forward
    navigation history (browser-style).
  * Shift+Tab peek-definition popup -- shows the declaration
    of the symbol under the cursor without leaving your spot.
  * Find in Files: dialog state (last query, mask, options)
    persists across sessions; fix command-code collision that
    was triggering Comment-selection instead.
  * Search | Jump to Asm: grayed out when no source is focused.
  * Wordstar prefix chord (Ctrl-K, Ctrl-Q) no longer eats its
    second key when the key matches a menu hot-key letter
    (e.g. Ctrl-K W).
  * Help | What's new...: this dialog. Loads CHANGES.TXT from
    the install directory at runtime.
  * About box and splash banner now show "-O3" suffix when the
    binary was built with the -O3 chain (BUILD_O3 define,
    flipped on by build-full-go32v2-o3.sh).

Compiler
  * fppu: reopen parent ppufile after deferred load. Fixes
    SIGSEGV / IDE "signal 291" when the trunk ctask scheduler
    left a parent ppu tempclosed while compiling a unit that
    triggered deferred reads.
  * browcol: replace TPointerDictionary sorted-collection with
    a chained hash table. Large speed-up for symbol browsing on
    big projects where the old O(N log N) insert dominated.


== IDE 1.0.15 / Compiler 3.3.2 ==

First version to stamp build commit short hash into the binary
banners (e.g. "3.3.2-a885a49" / "1.0.15-a885a49") via
compiler/revision.inc and packages/ide/ide_revision.inc emitted
by build-full-go32v2*.sh.

IDE
  * Ctrl+U Quick-Open by filename across project + -Fu/-Fi paths.
  * Find in Files (Ctrl+Shift+F), results in the Messages window.
  * Search | Jump to Asm Source (Alt+A); auto-recompiles -al
    if needed.
  * Open source files maximized + optional chromeless full-screen
    mode (F5 toggles); two new flags in Options | Editor.
  * S3-specific wide text-mode probe runs after VBE enumeration
    so S3-family chipsets expose 100/132-column modes the BIOS
    hides.
  * Recent Files uses move-to-front MRU on every open.
  * DOS Shell / File | Open anchor to the IDE's launch PWD.
  * Pentium CPU-target menu labels corrected (-CpPENTIUM2 was
    mis-labelled "PentiumMMX" -- selecting it on a real P55C
    crashed with invalid-opcode / page fault).

Compiler (i386)
  * New PENTIUMMMX cputype (P55C; P5 + MMX, no CMOV) between
    Pentium and Pentium 2.
  * -CpPENTIUM4 etc. now auto-define CPUX86_HAS_MMX / _SSEUNIT /
    _SSE2 to match the selected cputype -- no manual -d flags
    needed.
  * x86 peephole: imul by 2^n +/- 1 lowers to lea/shl + add/sub.

RTL (i386 / go32v2)
  * FillChar / FillWord / FillDWord / FillQWord MMX variants,
    auto-dispatched on MMX-capable CPUs without SSE2.
  * Move: startup probe detects broken 64-bit-precision emulator
    FPUs (em-dosbox, 86Box default) and falls back to a plain
    rep-movsl path that avoids x87 entirely.
  * Text-mode cursor scales to the actual VGA font height
    (16 scan lines in 80x25) instead of a hardcoded 7.
